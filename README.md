# VBL-BOT

Android companion app starter for Volleyball Legends.

## Current scope
- Android app shell with a simple status screen.
- Shortcut to Android Accessibility settings.
- Accessibility service is opt-in and only reports that it is connected.
- No game input automation, gameplay decisions, anti-cheat bypass, or Roblox account handling.

## Build
Open this repository in Android Studio (Hedgehog or newer), allow Gradle sync, then run the `app` configuration on an Android device.

## Permissions
The accessibility service is disabled by default and must be enabled manually in Android Settings. The starter service does not tap, swipe, or control Roblox.

## Project status
Prototype scaffold; not yet a playable or ball-detection app.
